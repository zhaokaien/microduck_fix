## 本仓库资料的阅读约定

- **已完成：** 有实物或实机结果。
- **进行中：** 已有方案，仍在验证。
- **待验证：** 来自推导、上游资料或社区经验，尚未在本机复现。

如果上游资料与本仓库记录冲突，先核对硬件版本与发布日期，再以可复现的实机日志为准。
