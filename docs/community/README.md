## 适合在群里问什么

- 硬件版本、接线和接口定义。
- 舵机 ID、标定、方向和总线问题。
- Radxa 镜像、启动、网络和服务。
- HAT、`imu_to_dxl` 与固件实测。
- 训练环境、模型导出与 sim2real。

提问时请带上版本、接线、日志、复现步骤和已经尝试过的修改。问题越可复现，越容易得到有效回答。

## HAT 扩展板

当前项目提供适配飞特 HD-1910 的 HAT 扩展板：

- 针对原版在高速通信和高负载下的稳定性问题进行优化。
- 接口带丝印，方便新手接线和排查。
- 支持飞特 HD-1910 方案。
- 当前团购价 **139 元/板，15 个成团**。

硬件在使用前仍需按自己的舵机、电池和整机版本完成检查与验证。

## 贡献规则

欢迎 Issue 和 PR，尤其是：

- 可复现的失败与成功记录。
- 带测试条件的电压、温度、频率和日志。
- 与具体硬件版本对应的修复。
- 对新手文档的纠错和补充。

不接受只写“我这边不行”或无法确认版本的结论。实测数据比推测更有价值。
