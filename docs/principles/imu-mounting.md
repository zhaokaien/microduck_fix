# IMU、坐标系与安装方向

[返回原理索引](README.md) · [返回首页](../../README.md)

## IMU 提供什么

一个六轴 IMU 通常包含：

- **加速度计**：测量比力，静止时可用来估计重力方向和倾角。
- **陀螺仪**：测量角速度，用于短时间内的快速姿态变化。

控制器会融合两类数据，得到更稳定的姿态估计。加速度计受振动影响，陀螺仪会积分漂移，因此安装、滤波和时间同步都很重要。

## 为什么安装方向这么重要

传感器有自己的 X、Y、Z 轴。软件把传感器数据转换为机器人躯干坐标系时，必须知道：

- 传感器在躯干上的安装位置。
- 三个轴分别指向机器人的什么方向。
- 正旋转方向是否符合右手坐标约定。
- 数据单位是 m/s²、g、rad/s 还是 deg/s。

安装方向错 90°、正负号反了，或把头部 IMU 当成躯干 IMU，都会让控制器误判身体姿态。

## 静止和倾斜怎么判断

静止时，加速度向量主要来自重力：

- 模长约为 1g。
- 竖直放置时，某个轴接近 ±1g。
- 前后倾斜时，重力在 X/Z 轴上的分量随之变化。

实际操作时不要只看“数值有变化”，要确认：

1. 倾斜方向与实物一致。
2. 回正后数值回到基线。
3. 旋转方向与正负号一致。
4. 重复放置后结果一致。

## 常见误差

| 误差 | 结果 |
|---|---|
| 零偏未校准 | 静止时姿态缓慢漂移 |
| 轴方向错误 | 机器人越走越歪或站立补偿反向 |
| 安装位置不代表躯干 | 头部或外壳运动被误认为身体倾斜 |
| 振动耦合 | 电机一转，姿态数据就跳 |
| 采样时间不同步 | 控制回路使用旧姿态数据 |
| 单位或顺序错误 | 仿真正常，真机异常 |

## 数据链路

IMU 可能通过以下方式接入：

- 舵机总线，使用固定设备 ID。
- 主板 I2C，使用设备地址。
- 独立 USB/串口。

无论哪种方式，都要确认总线编号、地址、权限、刷新率、时间戳和控制循环读取方式。

## 最低验证集

- 静止 60 秒，记录零偏和噪声。
- 三个轴分别正向、反向倾斜。
- 三个轴分别正向、反向旋转。
- 安装到整机后重复以上测试。
- 开启舵机动作，观察振动和电源干扰。

## 标定与“能用”的区别

读到了正确 ID，只说明通信成功；数据稳定、方向正确、时间对齐，才是控制器可以使用的 IMU。
