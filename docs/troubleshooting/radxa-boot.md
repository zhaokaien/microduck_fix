# 主控板不启动与 SD 卡问题

[返回排障索引](README.md) · [返回首页](../../README.md)

**一句话结论：** 先证明“镜像、卡、启动方式”三件事中哪一项有问题，再改系统配置；不要在无法启动的卡上盲改设备树。

**状态：** 记录框架，待补充实测

## 现象分类

| 现象 | 优先排查 |
|---|---|
| 电源灯不亮 | 电源、线材、接口、板卡短路 |
| 灯亮但无显示、无网络 | 镜像、SD 卡、启动介质 |
| 卡在固定阶段或反复重启 | 引导、设备树、内核、卡质量 |
| 以前能启动，换镜像后不能 | 镜像与板卡批次是否匹配 |
| 能启动但无线网络异常 | 无线芯片、设备树、驱动 |

## 最短排查步骤

1. 用已知可靠的电源和线材，不接 HAT 和舵机。
2. 重新下载镜像并核对校验值。
3. 换一张质量可靠的 SD 卡，重新写入。
4. 记录启动指示灯、串口输出或屏幕最后一行。
5. 对照镜像发布说明，确认板卡版本和启动方式。
6. 只恢复一个变量，再比较启动结果。

## 板上需要记录的信息

- 主板型号与内存。
- 背板丝印版本和无线模块。
- 使用的镜像、下载地址和 SHA256。
- 引导文件、DTB 和内核版本。
- 是否使用 HAT、USB 外设或特殊电源。
- 失败时的串口日志或屏幕照片。

## 不要一次做完的修改

- 同时替换引导、设备树和内核。
- 在目标板上直接改启动分区，却不保留原镜像。
- 把别人的完整启动分区直接复制到不同批次板卡。
- 主板还没稳定就继续接舵机排查。

## 完成标准

- 同一镜像和同一张卡能重复冷启动。
- 能进入系统并取得日志。
- 网络、串口和所需外设接口可用。
- 更换 SD 卡后仍能复现相同结果。
