# 绿灯亮但无 WiFi：Radxa 启动与 SD 卡排查

[返回排障索引](README.md) · [返回首页](../../README.md)

**一句话结论：** 绿色状态灯长亮后闪烁，不代表系统已经正常启动；本项目实际遇到的“绿灯在闪但没有 Wi-Fi 热点”，最终根因是 microSD 卡不兼容。

**状态：** 已实机复现并解决

## 本次故障现象

烧录镜像后上电：

1. 绿灯先长亮。
2. 随后绿灯开始闪烁。
3. 等待后仍然没有出现 Wi-Fi 热点。
4. 看起来板子“像是在运行”，但系统没有进入可用状态。

这说明指示灯只能作为辅助现象，不能替代串口日志。**心跳闪烁不等于系统启动成功。**

## 最短排查路径

1. 不接 HAT、舵机和摄像头，只保留主板和电源。
2. 使用 USB-TTL 连接电脑和 Radxa 调试串口。
3. 重新上电，抓取完整启动日志，确认卡在哪一步。
4. 用读卡器和 Ubuntu/Linux 电脑检查 SD 卡分区与文件系统。
5. 重新写入镜像，核对校验值和烧录错误。
6. 换一张经过验证的 microSD 卡复测。
7. 卡更换成功后再观察 Wi-Fi 热点和系统日志。

## USB-TTL 串口排查

主板没有 Wi-Fi、没有屏幕时，USB-TTL 是最直接的观察入口。

需要记录：

- USB-TTL 模块型号和芯片。
- 主板调试串口的针脚定义。
- TX、RX、GND 的接线方向。
- 串口设备名，例如 `/dev/ttyUSB0` 或 `COMx`。
- 波特率。
- 从上电到串口开始输出的时间。
- 最后一行日志和卡住阶段。

> 操作步骤待补充：Windows/macOS/Linux 下串口工具选择、端口参数和日志保存命令。

## SD 卡兼容性记录

| 卡 | 结果 | 说明 |
|---|---|---|
| SanDisk，包装标注 `tolerance` | 未正常工作 | 价格高，但没有解决启动和热点问题；具体型号待核对 |
| 朗科 32GB microSD | 正常工作 | 价格 45 元，更换后 Wi-Fi 热点很快出现 |

这个记录说明卡能被电脑识别、镜像能写入，并不能证明 Radxa 一定能从该卡启动。

建议保留：

- 一张已经验证能启动的卡作为基线。
- 卡的品牌、型号、容量和购买链接。
- 镜像版本和 SHA256。
- 成功与失败时的串口日志。

## 为什么换了卡后热点很快出现

在本机案例中，换卡后 Wi-Fi 热点很快出现，不需要等待很长时间。这个结果反过来证明：

- 主板主体和镜像大概率没有损坏。
- 原问题集中在启动介质兼容性或写入质量。
- LED 闪烁不能单独作为系统正常的判断依据。

该结论只适用于本机记录的具体卡和镜像，不代表所有同品牌存储卡都会出现相同问题。

## 其他常见现象

| 现象 | 优先排查 |
|---|---|
| 电源灯不亮 | 电源、线材、接口、板卡短路 |
| 灯亮但无显示、无网络 | 镜像、SD 卡、启动介质 |
| 卡在固定阶段或反复重启 | 引导、设备树、内核、卡质量 |
| 以前能启动，换镜像后不能 | 镜像与板卡批次是否匹配 |
| 能启动但无线网络异常 | 无线芯片、设备树、驱动 |

## 完成标准

- 同一镜像和同一张卡能重复冷启动。
- USB-TTL 能看到完整启动过程。
- 系统能进入并出现预期的 Wi-Fi 热点或网络连接。
- 热点不需要长时间等待，断电重启后仍能恢复。
- 能通过固定方式登录并查看系统日志。
- 更换 SD 卡后仍能复现相同结果。
