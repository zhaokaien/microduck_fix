# 舵机 ID、零位与方向错误

[返回排障索引](README.md) · [返回首页](../../README.md)

**一句话结论：** 舵机“能动”不等于标定正确。ID 唯一、零位一致、方向正确和机械限位必须逐项验证。

**状态：** 已建立流程，待整机数据

## 典型现象

- 总线扫描少一个或重复出现同一个 ID。
- 一个关节动作，另一个关节一起动。
- HOME 姿态和预期镜像或旋转。
- 某关节向反方向顶死。
- 写入标定后动作反而更乱。
- 舵机短时间发热、啸叫或电流过大。

## 最快定位

1. 断开机械负载或让关节处于自由状态。
2. 只接一个舵机，扫描并确认 ID。
3. 正转、反转一个小角度，确认方向和限位。
4. 建立一张身体部位与 ID 的对照表。
5. 逐个校准零位，不一次性写完全部关节。
6. 每次写完后断电重上电，再读取确认。

不要只写“正常”。必须留下能够复查的数值和方向定义。

## 零位与方向验证

- 零位：按机械设计定义的姿态读取位置。
- 方向：给正角度时关节朝约定方向运动。
- 限位：软件限位应早于机械顶死。
- 一致性：重新上电后读数与写入值相符。
- 整体性：15 个关节在 HOME 时没有自碰撞和线材拉扯。

## 常见误区

- 直接套用别人的零位和方向。
- 只改软件方向，不检查舵机安装方向。
- 舵机还带着力就手动扳动关节。
- 机械已经顶死，还继续增大输出。
- 没有备份原始标定文件。

## 完成标准

- 15 个 ID 唯一、稳定扫描。
- 每个关节方向和零位可以通过数值复查。
- HOME 可重复，断电重启后不漂移。
- 保持一段时间没有异常温升和啸叫。
