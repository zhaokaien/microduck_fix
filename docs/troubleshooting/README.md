# 按症状排障

[返回首页](../../README.md) · [完整索引](../README.md)

先按现象找到最接近的一篇。一次只改一个变量，并记录改前和改后的结果。

## 症状索引

| 现象 | 最优先检查 | 详细步骤 |
|---|---|---|
| 主控板完全没反应、卡在启动或反复重启 | 镜像、SD 卡、启动方式、板卡版本 | [主控板与 SD 卡](radxa-boot.md) |
| 单个舵机扫描不到 | 线序、供电、ID、波特率、协议 | [舵机标定](servo-calibration.md) |
| 多个舵机 ID 重复或动作对应错关节 | ID 表、方向、零位 | [舵机标定](servo-calibration.md) |
| 多舵机同时动作时丢帧、重启、抖动 | 电源、地线、总线负载、线材、HAT | [丢帧与总线](frame-drop.md) |
| 主控或舵机温度高、CPU 降频、响应变慢 | 散热、未使用服务、堵转、风道 | [过热与降频](overheat.md) |
| 嘉立创报价出现自定义层压或高额 SMT 换料费 | 层数、叠层、BOM、贴片方式 | [打板与 SMT](jlc-order.md) |
| IMU 数值跳、方向不对或静止漂移 | 型号、地址、安装方向、电源干扰 | [IMU 原理](../principles/imu-mounting.md) |
| 能站但一走就倒 | 标定、IMU、控制频率、模型参数 | [整机联调](../build/integration.md) |

## 通用排查原则

1. 先恢复到最小系统，只保留主控和必要电源。
2. 一次只改一个变量，并记录版本、接线和日志。
3. 先确认供电与地线，再怀疑协议和算法。
4. 单个设备正常、多个设备异常时，优先查共享资源。
5. 不把偶发成功当作问题解决，至少重复验证。

## 提交问题时请附带

- 主控板型号、版本和系统镜像。
- HAT、IMU、舵机型号及固件版本。
- 接线照片或针脚说明。
- 完整报错、日志时间范围和复现步骤。
- 已经尝试过的修改及结果。
