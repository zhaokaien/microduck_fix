## 常见费用来源

| 项目 | 常见问题 |
|---|---|
| 层数与叠层 | 误选自定义压层或特殊板厚 |
| 尺寸与数量 | 超出特价范围 |
| 阻焊/表面处理 | 选择高价工艺 |
| SMT 贴片 | 来料方式、换料费、拼板费 |
| BOM | 型号不完整、封装不一致、替代料不清 |
| 元件 | 整盘起订、库存不足、特殊封装 |

## 下单前检查

1. 明确 2 层还是 4 层，是否真的需要特殊叠层。
2. 检查板厚、铜厚、阻焊颜色和表面处理是否在特价范围。
3. 导出 BOM 前核对型号、封装、位号和 DNP。
4. 把常用电阻、电容改为可整盘采购的型号，避免高额换料费。
5. 确认是手焊、嘉立创贴片还是第三方贴片。
6. 保存报价页面、订单配置和 BOM 版本。

## 省钱的正确顺序

- 先减少不必要的特殊工艺。
- 再统一物料型号和封装。
- 再考虑拼板与数量。
- 最后才比较不同贴片方式。

不要为了省几元换料费，选择无法验证的替代料。

## 本项目采用的避坑思路

- 优先使用嘉立创当前支持的标准 4 层板和标准叠层，不误选“自定义压层”。
- 下单前核对免费特价是否仍然覆盖当前尺寸、数量和工艺。
- 常用的 0603 电阻、电容尽量按整盘或同页合并采购，减少 SMT 换料次数。
- 先确认工程 BOM 与实际采购型号一致，再选择贴片方式。
- 所有优惠、价格和规则以嘉立创下单当天页面为准，本页只保留方法与检查项。

## 首板验证

- 收到板后先目检短路、偏位、连锡和缺件。
- 限流上电，确认电源轨。
- 对关键网络做通断和电压测量。
- 记录批次、订单配置和不良位置。

## 完成标准

- 报价与最终下单配置一致。
- BOM 中每个物料都有明确型号和封装。
- 首板通过电源和关键接口检查。
- 订单资料可被下一位复刻者复现。
