## 这个仓库是做什么的

`microduck_fix` 是一个面向 MicroDuck 复刻新手的**第三方实战排错与资料导航仓库**。它汇总本人在 HAT 扩展板、`imu_to_dxl`、Radxa Zero 3W、飞特舵机、3D 打印装配和强化学习训练过程中的研究、操作步骤、失败原因与验证结果，帮助后来者快速判断下一步做什么，以及遇到问题时先查哪里。

这个仓库主要提供：

- **复刻路线**：从选型、采购、打板、打印、装配到上电、标定和训练。
- **痛点入口**：按“开不了机、舵机不转、总线丢帧、IMU 异常、温度过高”等现象直接定位。
- **实战记录**：记录踩过的坑、现象、原因、修复方法和验证条件。
- **原理说明**：解释供电、总线、IMU、控制循环、ONNX 与 sim2real。
- **上游导航**：整理官方 MicroDuck、fanhao 和 kissqy 项目中最适合进一步查阅的资料。

它不替代官方固件、硬件工程或完整训练项目，而是作为这些资料之上的**新手入口、复刻路线和排错层**。硬件版本、软件版本和实测结论会尽量明确标注，避免把推测写成通用结论。

## 推荐复刻路线

1. **定版本**：先确定舵机型号，再选对应的 3D 件、电子件和训练模型。
2. **备料与打样**：完成 BOM、PCB、结构件打印和五金采购。
3. **分体组装**：先做单腿、躯干、颈部和头部，再合并整机。
4. **电控点亮**：让 Radxa 能启动；分别验证 HAT、舵机总线和 IMU。
5. **整机标定**：逐个设置舵机 ID、零位与方向，再确认 IMU 安装方向。
6. **先站后走**：通过 HOME、扭矩、控制频率和信号完整性测试，再进入策略训练。

完整步骤与“每步完成标准”见 [整机复刻路线](docs/build/README.md)。

本项目最多三层，避免在一个问题里越点越深：

```text
L1  首页：判断自己在哪一步
     |
```

## 项目包含什么

MicroDuck 复刻可以拆成四块：

- **舵机与执行器**：官方使用 DYNAMIXEL XL330；国内复刻常改用飞特 HD-1910 或 2915，结构、参数、重量和训练模型都要对应调整。
- **电控**：Radxa Zero 3W、RPI Robot HAT 与 `imu_to_dxl`。HAT 负责电源转换和舵机总线，IMU 板提供躯干姿态。
- **机械**：外壳、关节、轴承、螺丝与不同舵机版本的 3D 打印件。
- **强化学习**：仿真环境、训练策略、ONNX 导出与 sim2real 验证。不同舵机不能直接套用官方模型。

各模块的边界、依赖关系与新手顺序见 [系统组成](docs/build/README.md#系统组成)。
