## 📌 项目简介

Microduck主要分成如下几个大的部分：
-- 0、舵机部分
舵机直白说就是带了控制的电机，用于小鸭的关节部分，从而小鸭受控做出动作。官方使用的是DYNAMIXEL 的XL330 智能串口舵机，国内复刻者主要使用深圳飞特公司的FT-HD-1910或飞特2915，舵机由于具体参数不同，重量不通，所以换舵机需要重新进行强化训练，不能直接使用官方的动作onnx文件。
-- 1、电控部分
电控部分主要包含如下几张卡：
（1）主控板：Radxa Zero 3W 1G，官方原来用2W测试的，也有复刻者用香橙派等替换的，我也查了Radxa zero 3E，这个和3W的区别只在3W是无线网卡，3E是有线网卡，理论上应该也可以
（2）elect RPI Robot HAT板：这个板子主要两个作用，一是将2S电池电源的6-8V的电压转换成稳定的5V电压给上面的主控板供电，一是15个舵机的主控电路，官方已开源该板子的PCB工程源文件，但是适配飞特舵机的时候有一些bug，后边会针对该问题进行fix
（3）IMU_TO_DXL板：这个主要为鸭子提供3D加速度计和3D陀螺仪，官方没有开源，但是比较简单，已经有现成的复刻成功的开源的PCB源文件
-- 2、机械部分
机械部分主要包括鸭子的外壳组装件、部分轴承、螺丝等五金件。这部分大部分都可以用3D打印实现了，只是舵机不同，细微上有些差别，需要使用不通版本的3D打印文件。
